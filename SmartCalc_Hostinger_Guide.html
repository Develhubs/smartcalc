SmartCalc Deployment Guide for Hostinger

A complete guide to deploying your SmartCalc website on Hostinger web hosting

Overview

This guide will walk you through the process of deploying the SmartCalc calculator website on your Hostinger web hosting server. You have two main options for deployment, depending on your Hostinger plan and whether you need backend functionality.

Note: Before starting the deployment process, make sure you have a Hostinger account and have set up your domain name.

Step 1: Export SmartCalc Code

  1. Download Code: First, download the code from Replit by clicking on the three dots (...) in the file browser and selecting "Download as zip".
  2. Save and Rename: Save the file to your computer and rename it to "SmartCalc.zip" if needed.
  3. Extract Files: Extract the downloaded zip file to a folder on your computer.

Step 2: Prepare the Project

  1. Install Node.js: Make sure you have Node.js installed on your computer. If not, download and install it from nodejs.org.
  2. Open Terminal: Open a terminal or command prompt and navigate to the extracted SmartCalc folder.
  3. Install Dependencies: Run the following command to install all required dependencies: 
    npm install
  4. Build the Project: Create a production build of the project: 
    npm run build

    This will create a dist directory with all the built files.

Important: The build process may take a few minutes to complete. Make sure it finishes successfully before proceeding to the next step.

Step 3: Deploy to Hostinger

Static Deployment
Full-Stack Deployment

Option A: Static Deployment (Frontend Only)

This option is best for basic Hostinger plans and doesn't require Node.js support.

  1. Log in to Hostinger: Access your Hostinger control panel (hPanel).
  2. Navigate to File Manager: Go to "Website" → "File Manager" or use FTP software like FileZilla to connect to your server.
  3. Open public_html: Navigate to the public_html directory (or the directory configured for your domain).
  4. Upload Files: Upload the contents of the dist/public directory from your local build to this directory.
    Tip: You can select all files in the dist/public directory and drag them to your File Manager window, or use the upload functionality.
  5. Create .htaccess file: Create a new file named .htaccess in your public_html directory with the following content: 
    <IfModule mod_rewrite.c>
  RewriteEngine On
  RewriteBase /
  RewriteRule ^index\.html$ - [L]
  RewriteCond %{REQUEST_FILENAME} !-f
  RewriteCond %{REQUEST_FILENAME} !-d
  RewriteRule . /index.html [L]
</IfModule>
  6. Verify Deployment: Visit your domain in a web browser to check if the website is working properly.

Option B: Full-Stack Deployment (with Backend)

Use this option if you need backend functionality and have a Hostinger plan with Node.js support.

Requirement: This option requires a Hostinger plan that supports Node.js applications, typically Premium or Business plans.
  1. Log in to Hostinger: Access your Hostinger control panel (hPanel).
  2. Create Application Directory: Use File Manager or FTP to create a directory for your application (e.g., smartcalc).
  3. Upload Files: Upload the following to your application directory:
    • The entire dist directory from your local build
    • package.json and package-lock.json files
  4. Create Environment File: Create a .env file in your application directory with any required environment variables: 
    NODE_ENV=production
PORT=3000
# Add other environment variables if needed
# DATABASE_URL=mysql://username:password@localhost:3306/database_name
# ANTHROPIC_API_KEY=your_api_key_here
  5. Install Dependencies (if SSH is available):
    • Connect to your server via SSH from Hostinger's control panel
    • Navigate to your application directory
    • Run: npm install --production
    Note: If SSH is not available on your plan, you'll need to upload the node_modules directory from your local project.
  6. Configure Node.js Application:
    • In Hostinger's hPanel, go to "Website" → "Node.js"
    • Click "Create a Node.js app"
    • Configure the settings:
      • Entry Point: dist/index.js
      • Node.js Version: Select the latest available (16+)
      • Application URL: Your domain or subdomain
    • Save and start the application
  7. Configure Domain: Make sure your domain is pointing to your Node.js application in the Hostinger domain settings.
  8. Verify Deployment: Visit your domain to check if everything is working properly.

Troubleshooting

Common Issue: 404 Page Not Found

Possible causes:

  • The .htaccess file is missing or incorrectly configured
  • Files were uploaded to the wrong directory
  • Your domain's DNS is not properly configured

Solutions:

  • Double-check the content of your .htaccess file
  • Verify that all files, especially index.html, are in the correct directory
  • Check your domain settings in Hostinger's control panel

Common Issue: Node.js Application Not Starting

Possible causes:

  • Entry point incorrectly specified
  • Missing dependencies
  • Environment variables not set properly

Solutions:

  • Check Hostinger's Node.js logs for specific error messages
  • Verify the entry point path is correct (should be dist/index.js)
  • Make sure all dependencies are installed
  • Check that your .env file has all required variables

Common Issue: White Screen or Blank Page

Possible causes:

  • JavaScript errors in the application
  • Missing CSS or JavaScript files
  • Incompatible browser or settings

Solutions:

  • Check your browser's developer console for error messages
  • Verify all required files are uploaded correctly
  • Clear your browser cache or try a different browser

Maintaining Your Website

After deploying your SmartCalc website, you might need to update it in the future:

  1. Make Changes Locally: Update your code on your local machine.
  2. Rebuild: Run npm run build to create a new build.
  3. Upload Updated Files:
    • For static deployment, update the files in your public_html directory
    • For full-stack deployment, update your entire application directory
  4. Restart Node.js App (if applicable): If you're using the full-stack option, restart your Node.js application in Hostinger's control panel.
